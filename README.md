# LinketinderDesafioZG - MVP

### Projeto oferecido como desafio pela iniciativa da Acelera ZG.

### O linketinder busca pegar candidatos e empresas fazendo com que eles, entre si, deem match caso as curtidas sejam reciprocas.

### Feature: Opção de ver os matchs já feitos com o banco de dados presetado dentro do sistema.

## Para rodar o projeto:

```
1. Faça um clone do projeto em seu diretório

2. Abra a pasta 'LinketinderDesafioZG' como diretório principal do projeto

3. Instale o Groovy SDK (recomendado intellij, mais amigável para configurar)

4. Rode o projeto pelo 'app.groovy'

```
